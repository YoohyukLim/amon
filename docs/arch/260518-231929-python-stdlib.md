# ADR: Python 3 stdlib only (Go/Bash 미채택)

- Date: 2026-05-18
- Status: Accepted

## Context

amon 은 macOS 와 Linux 양쪽에서 동작해야 한다. 구현 언어/배포 형태를 선택해야 한다.

## Options considered

- **(A) Python 3 stdlib** — single `.py` 파일, `chmod +x` + shebang 으로 실행. 외부 의존 0.
- **(B) Bash + jq** — `tail -F` 와 `jq -c` 조합. 초경량.
- **(C) Go single binary** — `darwin-arm64`, `linux-amd64` 두 binary 빌드/배포.

## Decision

**(A) Python 3 stdlib only** 채택. 외부 라이브러리 (requests, click, watchdog 등) 도 모두 금지.

## Rationale

- macOS / Linux 모두 `python3` 가 기본 설치되어 있음 (macOS 12+, 모든 주요 Linux 배포판). 설치 0단계.
- 모니터링 로직은 (i) 프로세스 정보 추출 (`lsof`, `pgrep`), (ii) jsonl tail (파일 offset 추적), (iii) 이벤트 파싱 (json), (iv) 시간 기반 idle 감지 — 모두 stdlib (`subprocess`, `json`, `os`, `time`, `argparse`, `signal`) 로 충분.
- Bash + jq 는 multi-tail / 시간 기반 idle 타이머 / snapshot 출력 집계 모두 짜증나는 영역. 단순 한 줄짜리는 좋지만 amon 의 표면이 그 이상.
- Go single binary 는 의존성 0 이지만 (i) cross-platform 빌드 파이프라인 필요, (ii) 단일 사용자 도구에 과함, (iii) 빠른 반복 수정에 불리.

## Consequences

- **외부 lib 금지 룰 유지** — 향후 fsnotify/inotify 등이 매력적이어도 추가 금지. 필요해지면 이 ADR 을 superseded 로 표시하고 새 결정.
- Python 3.8+ 가정 (f-string, walrus, type hint 일부). macOS 12+ 와 Ubuntu 20.04+ 가 만족.
- 단일 파일 → 배포는 `cp amon ~/.local/bin/` 또는 symlink. 패키징 (`pip install`, `setup.py`) 안 함.
- 외부 lib 없이 multi-tail 을 구현해야 함 → poll-based loop 으로 처리 (별도 ADR 검토 없이 단순 sleep 폴링).
